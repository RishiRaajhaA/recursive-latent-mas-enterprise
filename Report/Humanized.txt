Chapter 1.1
Customer service, logistics fulfillment, warranty processing and inventory management are increasingly relying on autonomous decision-making systems.
These agents are more than just question answerers. They must call external APIs, look up company policies, decompose complex customer goals, verify relational database status, process transaction updates and make sure all final constraints are met.
Instead of producing an answer in one feed-forward pass, an agent would work iteratively. It is thinking. It chooses a tool. It sucks up what comes back.”
The wrong tool, badly formatted parameters or a rushed assumption can snowball into policy violations or outright task failure.

Chapter 2.1
Interactive decision-making architectures have emerged as a more powerful alternative to static prompt generation in the development of autonomous reasoning systems powered by Large Language Models. ReAct integrates natural language reasoning with commands in external software. It showed substantial gains over standard chain-of-thought prompting on multi-hop question answering and decision-making benchmarks.
To reduce early execution errors, Shinn et al. [1] proposed Reflexion, an architecture for language agents to obtain verbal reinforcement learning through linguistic self-reflection. When a trajectory fails, the agent produces a textual evaluation of the trajectory and stores it in working memory for future rollouts. However, the nature of natural language constrains standard ReAct and verbal reflection frameworks. Suppose an agent gets a wrong return from a database or chooses a wrong API schema at the beginning. Later criticisms of it tend to be verbose, illogical, or obsessed with the earlier mistake. The context window fills with the critique text, one token at a time. And so you have a compounding failure loop that leaves the job un-done.

Chapter 2.2
Single agents pipelines are unstable and the cognitive system for complex reasoning is heavy loaded, thus multi-agent systems are very popular. Wu et al. [3] proposed a modular framework (AutoGen) that enables different expert personas to conversate with each other. Agents like planners, programmers and code reviewers break down complex goals and coordinate with structured prompts. Specialization helps break down problems, but traditional configurations still communicate only in text. Agents must serialize plans, summary of status and critiques into natural language tokens that can be parsed and re-encoded by the next agent.

The Participation Ratio for over two hundred random subsets of ninety tasks suggests that Latent ReAct uses a strictly lower-dimensional and more focused representational subspace than Text ReAct. So at round zero the text occupies twenty-two point zero dimensions but the latent representation manifold occupies an average of eighteen point nine effective dimensions. Both designs exhibit continuous representational compression over iterative runs. By round three their effective dimensionality (fifteen point two dimensions for latent, sixteen point eight dimensions for text) has been reduced by about twenty to twenty-three percent.
This interpretation is consistent with the persistent dimensionality gap observed across more than 97% of bootstrap subsamples, where continuous latent deliberation filters away irrelevant lexical variation and constrains multi-agent reasoning to a compact semantic subspace directly relevant to task constraints. Importantly, recurrent latent passing does not suffer from catastrophic dimensional collapse, as it preserves sufficient representational capacity to encode multi-step corporate workflows, as evidenced by the preservation of 15.2 effective dimensions at full recursion depth.
