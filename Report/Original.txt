Abstract
The internal states of the agents were analyzed and showed near-orthogonal functional specialization in Latent ReAct (CosSim ≤ 0.087, Dij ≈ 51.5). In contrast, Text ReAct has a high level of verbal overlap (CosSim > 0.998). The statistical analysis does not result in a significant outcome and I report it as such. Global average states do not linearly discriminate task performance. Tool-specific localized representations might predict execution reliability better and should be investigated further.

Chapter 1.1
We increasingly depend on autonomous decision-making systems for customer service, logistics fulfillment, warranty processing and inventory management.
These agents do more than answer questions. They have to call external APIs, search company policies, break down complicated customer goals, check relational database status, handle transaction updates, and make sure all final constraints are fulfilled.
An agent would run iteratively instead of producing an answer in a single feed-forward pass. It thinks. It picks a tool. It sucks up what returns.
A wrong tool, poorly formatted parameters, or a hasty assumption can snowball into policy violations or outright task failure.

Chapter 2.1
In the development of autonomous reasoning systems powered by Large Language Models, interactive decision-making architectures have replaced static prompt generation. ReAct combines natural language reasoning with commands that are executed in external software. It showed clear improvements over standard chain-of-thought prompting on multi-hop question answering and decision-making benchmarks.
In order to overcome early execution errors, Shinn et al. [1] created Reflexion, an architecture that provides language agents with verbal reinforcement learning through linguistic self-reflection. When a trajectory fails, the agent generates a retrospective textual evaluation and saves it in working memory to guide subsequent rollouts. That said, standard ReAct and verbal reflection frameworks are limited by the nature of natural language. Say an agent gets a wrong return from a database or picks a wrong API schema at the beginning. Later criticisms of it are often verbose, illogical, or fixated on the prior mistake. Context window fills with critique text, one token at a time. And so you have a compounding failure loop that leaves the job undone.

Chapter 2.2
Multi-agent systems are very popular due to the instability of single agents pipelines and the heavy load of the cognitive system for complex reasoning. Wu et al. [3] proposed AutoGen, a modular framework that allows different expert personas to chat with each other. The agents, such as planners, programmers, and code reviewers, break down complicated goals and coordinate using structured prompts. Specialization does help with problem decomposition but conventional setups still only talk by text. Agents must serialize plans, status summaries, and critiques into natural language tokens that the next agent can parse and re-encode.

Chapter 4.3
Evaluation of the Participation Ratio over two hundred random subsets of ninety tasks shows that Latent ReAct operates inside a strictly lower-dimensional, more focused representational subspace than Text ReAct. Text occupies twenty-two point zero dimensions at round zero, but the latent representation manifold occupies an average of eighteen point nine effective dimensions. During iterative runs, both designs exhibit continuous representational compression; by round three, their effective dimensionality (fifteen point two dimensions for latent, sixteen point eight dimensions for text) has dropped by about twenty to twenty-three percent.
The interpretation that continuous latent deliberation filters out superfluous lexical variation and confines multi-agent reasoning to a compact semantic subspace directly relevant to task constraints is consistent with the persistent dimensionality gap seen across more than 97% of bootstrap subsamples. Crucially, recurrent latent passing prevents catastrophic dimensional collapse by maintaining enough representational capacity to encode multi-step corporate workflows, as demonstrated by the preservation of 15.2 effective dimensions at full recursion depth.

This rigorous null discovery offers significant technical insight: macroscopic, pooling system representations (Hr) do not encode downstream job fulfillment in a simple, linear geometric transformation. Since Hr is a mean spanning several functional roles, averaging smoothes out local, agent-specific signals that regulate tool execution integrity. Remarkably, a marginal predictive signal for task outcome (Area Under the Curve of 0.64, permutation p = 0.05) was obtained from an exploratory linear probe on isolated Tool-Caller representations (H2). We specifically state that independent validation on different benchmark cohorts is necessary before any firm conclusions can be made, and we firmly maintain this as an exploratory finding.
