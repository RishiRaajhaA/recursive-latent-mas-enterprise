\section{Relational Database Schema}
The underlying SQLite relational database consists of five basic entity tables that maintain state during multi-turn customer transactions. Customer identifiers, contact information, primary shipping addresses, and loyalty membership tiers are kept up to date in the \texttt{users} table. Transaction identifiers, customer foreign keys, placement timestamps, fulfillment status, and order totals are all stored in the \texttt{orders} table. Product purchases, quantities, unit pricing, return flags, and policy return eligibility are all itemized in the \texttt{order\_items} table. Warehouse stock levels, product classifications, catalog inventories, and restocking restrictions are all monitored via the \texttt{products} database. Lastly, the \texttt{returns} table keeps track of inspection statuses, submission dates, return item justifications, and refund authorizations.
